# Politique de sécurité

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir d'issue publique. Utilisez le formulaire privé de GitHub :
[Security → Report a vulnerability](https://github.com/KarnasZiad/ShieldGate/security/advisories/new).

Indiquez la version ou le commit concerné, les étapes pour reproduire et l'impact estimé. L'objectif
est d'accuser réception sous 72 heures et de publier un correctif accompagné d'un avis de sécurité.

## Périmètre

Toute faiblesse permettant de contourner l'authentification, la MFA, une politique d'autorisation,
de lire ou modifier des données d'un autre compte, ou d'altérer le journal d'audit.
